# Tetris assets

- **Masonry Tetris clone UI** (Title, blocks, play, pause, background frame, panel) — [OpenGameArt: Tetris Clone - Masonry](https://opengameart.org/content/tetris-clone-masonry), **CC0**
- **UnLucky Studio Tetris pack** (menu background + piece art) — [UnLucky Studio free Tetris assets](https://unluckystudio.com/free-game-artassets-15-tetris-game-assets/), **CC0**
- Mino cell textures in `minos/` are derived (bevel + masonry grain + Guideline colors) for cell-based playfield rendering.

Gameplay rules follow the public Tetris Guideline community documentation (7-bag, SRS kicks, hold, lock delay, ghost, next queue) as documented on tetris.wiki / Hard Drop. This is an unofficial fan project — not affiliated with The Tetris Company.
